GOATED OFT regtest bridge — deploy & wiring handoff

A LayerZero V2 OFT bridge for GOATED across two EVM regtest chains, relayed end-to-end by oh-my-lazier (OpenDVN + OpenExecutor). Deploy scripts, worker configs, and a compose fragment — validated bidirectionally on two local chains before goat-geth.

builds green ×3 A→B delivered B→A delivered autonomous 2-worker relay 2026-07-20

01Topology

Chain A (EVM-regtest) is the source and holds the GOATED supply; chain B is goat-geth. GOATED here is oh-my-lazier's mintable TestOFT, mirroring testnet3's live "GOATED TestOFT" — preminted 1,000,000 on A, 0 on B. Two OpenDVN instances secure each pathway; two worker processes drive them.

02Why two workers

The runtime rule

The oh-my-lazier worker hard-requires ≥2 required DVNs in the receive-ULN config (go/internal/dvn/dvn.go) and each process verifies exactly one DVN. A single-DVN pathway is paused to MANUAL_REVIEW at runtime — --skip-onchain-check does not bypass it.

The shape

worker-1 runs OpenExecutor + the primary OpenDVN; worker-2 runs the secondary OpenDVN. Separate databases; they coordinate purely through on-chain PayloadVerified events. The executor delivers once both DVNs have verified.

Enforced options on the OApp already supply the lzReceive gas (250,000). Callers must send with empty extraOptions — adding a lzReceive option too triggers a duplicate-option revert (0x56b04d0d).

03Run it

From ~/workspace/goat-dev/oh-my-lazier. Dependencies installed once via npm ci; Go 1.23+ (auto-fetches 1.26.4 per go.mod).

  1. Bring up both chains — chain A must produce blocks continuously

    # chain A: any source EVM. On anvil, use --block-time so packets confirm.
anvil --chain-id 31337 --block-time 2 --port 18545
# chain B: goat-geth from the goat-regtest stack (RPC :8545)

  2. Fund deployer + both workers on goat-geth

    # funder = 0xbc00…dCA2 (goat-regtest README key)
cast send 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266 --value 100ether \
  --private-key 0xdd11c216…107f --rpc-url http://127.0.0.1:8545 --legacy
# repeat for 0x7099…79C8 (worker-1) and 0x3C44…93BC (worker-2)

  3. Deploy + wire both chains, emit configs

    REGTEST_A_HOST_RPC_URL=http://127.0.0.1:18545 REGTEST_A_CHAIN_ID=31337 \
REGTEST_B_HOST_RPC_URL=http://127.0.0.1:8545  REGTEST_B_CHAIN_ID=<goat-geth chainId> \
REGTEST_B_CONTAINER_RPC_URL=http://goat-regtest-geth-node:8545 \
npm run regtest:deploy

  4. Generate the two worker keystores

    E2E_WORKER_PRIVATE_KEY=0x59c6995e… REGTEST_KEYSTORE_PASSWORD=<pw> \
  go run ./go/cmd/e2ekeystore -out tmp/regtest/worker-1-keystore.json -password-env REGTEST_KEYSTORE_PASSWORD
E2E_WORKER_PRIVATE_KEY=0x5de4111a… REGTEST_KEYSTORE_PASSWORD=<pw> \
  go run ./go/cmd/e2ekeystore -out tmp/regtest/worker-2-keystore.json -password-env REGTEST_KEYSTORE_PASSWORD

  5. Start Postgres (2 DBs) + both workers

    REGTEST_KEYSTORE_PASSWORD=<pw> \
  docker compose -f deploy/regtest/docker-compose.regtest.yml up -d --build

  6. Smoke test a GOATED transfer

    REGTEST_A_HOST_RPC_URL=http://127.0.0.1:18545 \
REGTEST_B_HOST_RPC_URL=http://127.0.0.1:8545 \
npm run regtest:send            # A→B ; add REGTEST_SEND_DIRECTION=ba for reverse
